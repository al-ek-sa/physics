# Определение скорости движения объекта по смазу на фотографии

## Физический проект: компьютерное зрение и кинематика

**Тема:** Исследование возможности определения скорости движущегося объекта по длине смаза на цифровой фотографии с использованием компьютерного зрения.

Проект использует Python и OpenCV для обнаружения вытянутого следа (motion blur), измерения его длины в пикселях и вычисления скорости движения объекта при известном времени экспозиции и масштабе изображения.

---

# 1. Цель, задачи и гипотеза

## Цель

Экспериментально исследовать возможность измерения скорости движущегося объекта по длине его смаза на фотографии и оценить точность автоматизированного метода компьютерного зрения.

## Задачи

1. Изучить физику формирования смаза при фотографировании движущегося объекта.
2. Вывести формулу связи длины смаза, времени экспозиции и скорости.
3. Разработать метод калибровки изображения — переход от пикселей к метрам.
4. Реализовать алгоритм обработки фотографии на Python.
5. Провести измерения для нескольких скоростей и/или значений экспозиции.
6. Сравнить вычисленную скорость с контрольным измерением.
7. Рассчитать абсолютную и относительную погрешности.
8. Определить ограничения метода и предложить улучшения.

## Гипотеза

Если движение объекта в течение экспозиции приблизительно равномерно, направление движения лежит в плоскости калибровки, а время экспозиции известно, то длина смаза на фотографии пропорциональна скорости объекта. Следовательно, скорость можно оценить по длине смаза с помощью компьютерного зрения.

# 2. Теоретическая часть

## 2.1. Равномерное движение

При равномерном прямолинейном движении скорость постоянна:

\[
v=\frac{\Delta s}{\Delta t}
\]

где:

- \(v\) — скорость, м/с;
- \(\Delta s\) — путь, м;
- \(\Delta t\) — интервал времени, с.

В течение экспозиции фотокамеры объект движется на расстояние \(\Delta s\). Если движение равномерное, то:

\[
\Delta s=vT
\]

где \(T\) — время экспозиции.

Отсюда:

\[
\boxed{v=\frac{\Delta s}{T}}
\]

---

## 2.2. Как возникает смаз

Фотосенсор регистрирует свет не мгновенно, а в течение некоторого интервала времени \(T\).

Если объект движется, его изображение последовательно занимает разные положения на сенсоре. В результате в изображении регистрируется не одна точка, а набор положений объекта, объединённый в вытянутый след.

В идеализированном случае:

\[
L=vT
\]

где:

- \(L\) — длина смаза в физическом пространстве, м;
- \(v\) — скорость объекта, м/с;
- \(T\) — экспозиция, с.

Поэтому:

\[
\boxed{v=\frac{L}{T}}
\]

### Пример

Объект движется со скоростью \(2\ \text{м/с}\), а экспозиция равна \(0{,}05\ \text{с}\).

\[
L=2\cdot0{,}05=0{,}1\ \text{м}
\]

За время фотографирования объект перемещается на 10 сантиметров. На изображении его след должен соответствовать этому перемещению с учётом масштаба.

# 3. Переход от пикселей к метрам

Компьютерное зрение измеряет расстояние в пикселях. Для вычисления физической скорости необходим масштаб.

Пусть на изображении известный отрезок физической длины \(D\) занимает \(N\) пикселей.

Тогда масштаб:

\[
k=\frac{N}{D}
\]

где \(k\) измеряется в пикселях на метр:

\[
[k]=\frac{\text{px}}{\text{m}}
\]

Физическая длина смаза:

\[
L=\frac{L_{\text{px}}}{k}
\]

Подставим в формулу скорости:

\[
v=\frac{L}{T}
\]

Получаем:

\[
\boxed{v=\frac{L_{\text{px}}}{kT}}
\]

где:

- \(L_{\text{px}}\) — длина смаза, пиксели;
- \(k\) — масштаб изображения, пикселей/метр;
- \(T\) — экспозиция, секунды;
- \(v\) — скорость, м/с.

## Альтернативная форма через известный объект

Если известный объект длиной \(D\) занимает \(N\) пикселей, то:

\[
k=\frac{N}{D}
\]

Следовательно:

\[
v=\frac{L_{\text{px}}D}{NT}
\]

\[
\boxed{v=\frac{L_{\text{px}}D}{NT}}
\]

Эта формула удобна, если масштаб рассчитывается непосредственно из линейки, разметки или другого объекта известного размера.

---

# 4. Пример расчёта

Допустим:

- длина смаза \(L_{\text{px}}=120\) px;
- известный отрезок \(D=0{,}5\) м;
- этот отрезок на фотографии занимает \(N=250\) px;
- выдержка \(T=1/100\) с.

Масштаб:

\[
k=\frac{250}{0{,}5}=500\ \text{px/m}
\]

Физическая длина смаза:

\[
L=\frac{120}{500}=0{,}24\ \text{м}
\]

Время экспозиции:

\[
T=\frac{1}{100}=0{,}01\ \text{с}
\]

Скорость:

\[
v=\frac{0{,}24}{0{,}01}=24\ \text{м/с}
\]

Перевод в км/ч:

\[
v_{\text{км/ч}}=3{,}6v
\]

\[
v_{\text{км/ч}}=86{,}4\ \text{км/ч}
\]

# 5. Устройство алгоритма

Алгоритм состоит из следующих этапов.

## Этап 1. Загрузка изображения

Изображение считывается с диска при помощи OpenCV.

## Этап 2. Выбор области интереса

При необходимости пользователь задаёт прямоугольную область (ROI), содержащую смаз. Это помогает исключить посторонние объекты.

ROI задаётся координатами:

```text
x y width height
```

Например:

```bash
--roi 100 150 500 300
```

## Этап 3. Преобразование в оттенки серого

Цветное изображение преобразуется в grayscale:

\[
I_{\text{gray}}=0{,}299R+0{,}587G+0{,}114B
\]

(в OpenCV преобразование выполняется стандартной функцией `cvtColor`).

## Этап 4. Фильтрация шума

Используется небольшое гауссово сглаживание. Оно уменьшает влияние мелкого шума и одиночных пикселей.

## Этап 5. Бинаризация

Изображение превращается в маску, где пиксели смаза выделены, а фон подавлен.

Используется:

- автоматический порог Отсу;
- либо заданный вручную порог;
- возможность инвертировать бинаризацию для тёмного смаза на светлом фоне.

## Этап 6. Поиск связных компонент

Алгоритм находит связные группы пикселей. Кандидаты фильтруются по:

- площади;
- вытянутости.

Вытянутость определяется отношением:

\[
A_r=\frac{w}{h}
\]

для горизонтально-вытянутого объекта либо:

\[
A_r=\frac{\max(w,h)}{\min(w,h)}
\]

для произвольного направления.

## Этап 7. Измерение длины

Реализованы два метода.

### Метод PCA

PCA (Principal Component Analysis) определяет главное направление вытянутого объекта.

1. Координаты пикселей компоненты рассматриваются как набор точек.
2. Рассчитывается ковариационная матрица.
3. Находится собственный вектор с максимальным собственным значением — направление максимального разброса.
4. Все пиксели проецируются на это направление.
5. Длина определяется диапазоном проекций.

Для уменьшения чувствительности к отдельным шумовым пикселям используются 1-й и 99-й процентили.

\[
L_{\text{px}}=P_{99}-P_1
\]

Метод PCA подходит для смаза, направленного под произвольным углом.

### Метод повёрнутого прямоугольника

OpenCV строит минимальный повёрнутый прямоугольник, содержащий компоненту.

Длина смаза определяется как длинная сторона прямоугольника:

\[
L_{\text{px}}=\max(w_r,h_r)
\]

где \(w_r\) и \(h_r\) — размеры повёрнутого прямоугольника.

# 6. Погрешности измерений

Результат зависит от нескольких измеряемых величин:

\[
v=\frac{L_{\text{px}}}{kT}
\]

Предполагая независимые погрешности, относительная погрешность скорости приближённо равна:

\[
\boxed{
\frac{\sigma_v}{v}
=
\sqrt{
\left(\frac{\sigma_L}{L}\right)^2+
\left(\frac{\sigma_k}{k}\right)^2+
\left(\frac{\sigma_T}{T}\right)^2
}
}
\]

где:

- \(\sigma_L\) — погрешность длины смаза;
- \(\sigma_k\) — погрешность масштаба;
- \(\sigma_T\) — погрешность времени экспозиции;
- \(\sigma_v\) — погрешность скорости.

Абсолютная погрешность:

\[
\boxed{\sigma_v=v\cdot\frac{\sigma_v}{v}}
\]

## Основные источники погрешности

1. Неточность определения границ смаза.
2. Неравномерное распределение яркости.
3. Шум сенсора.
4. Наличие фоновых объектов.
5. Неправильно выбранный порог бинаризации.
6. Неточность масштаба.
7. Неточность времени экспозиции.
8. Изменение скорости во время экспозиции.
9. Перспективные искажения.
10. Движение камеры.
11. Смаз не соответствует строго перемещению центра объекта: форма, размеры объекта и особенности оптики могут влиять на вид следа.
12. Rolling shutter — считывание разных строк сенсора в разные моменты времени.

# 7. Эксперимент

## Оборудование

- смартфон или цифровая камера с ручным управлением выдержкой;
- движущийся объект, например игрушечная машинка;
- линейка или измерительная лента;
- неподвижная камера;
- компьютер с Python;
- освещение;
- желательно штатив.

## Рекомендуемая установка

Камера устанавливается неподвижно.

В плоскости движения объекта размещается линейка или другой объект известной длины, используемый для определения масштаба.

Объект движется приблизительно параллельно плоскости изображения.

Схема:

```text
                 Камера
                   |
                   v
        ------------------------
        |                      |
        |   область движения    |
        |                      |
        |  ---> объект          |
        |                      |
        |  [линейка/шкала]      |
        ------------------------
```

Важно: калибровочный объект должен находиться примерно в той же плоскости, что и движущийся объект. Если он расположен ближе или дальше от камеры, масштаб может отличаться из-за перспективы.

## План эксперимента

Для каждой серии:

1. Установить камеру.
2. Выбрать фиксированное положение камеры.
3. Измерить масштаб.
4. Записать время экспозиции.
5. Сделать фотографию движущегося объекта.
6. Обработать фотографию программой.
7. Получить длину смаза и скорость.
8. Повторить измерение несколько раз.
9. Сравнить результат с контрольной скоростью.

Желательно исследовать несколько режимов:

| № | Экспозиция | Скорость | Ожидаемый смаз |
|---|---:|---:|---|
| 1 | 1/500 с | низкая | короткий |
| 2 | 1/250 с | низкая | длиннее |
| 3 | 1/100 с | средняя | заметный |
| 4 | 1/50 с | средняя | длинный |
| 5 | 1/30 с | высокая | очень длинный |

Таблица — пример планирования, а не экспериментальные данные.

# 8. Контрольное измерение скорости

Для проверки результата можно использовать независимый метод.

Например, если объект проходит известное расстояние \(S\) за время \(t\):

\[
v_{\text{контр}}=\frac{S}{t}
\]

Для нескольких измерений:

\[
\overline{v}=\frac{1}{n}\sum_{i=1}^{n}v_i
\]

## Абсолютная ошибка

\[
\Delta v=|v_{\text{CV}}-v_{\text{контр}}|
\]

## Относительная ошибка

\[
\varepsilon=
\frac{|v_{\text{CV}}-v_{\text{контр}}|}
{v_{\text{контр}}}\cdot100\%
\]

где \(v_{\text{CV}}\) — скорость, рассчитанная методом компьютерного зрения.

# 10. Запуск программы

Базовый запуск:

```bash
python motion_blur.py photo.jpg --exposure 0.01 --scale 500
```

Здесь:

- `photo.jpg` — фотография;
- `--exposure 0.01` — экспозиция 0,01 секунды (1/100 с);
- `--scale 500` — 500 пикселей соответствуют одному метру.

Например, если линейка длиной 0,5 м занимает 250 пикселей:

\[
k=\frac{250}{0{,}5}=500\ \text{px/m}
\]

## Вывод результата

Программа выводит:

- длину смаза в пикселях;
- длину смаза в метрах;
- угол движения;
- площадь выделенной компоненты;
- оценку вытянутости;
- скорость в м/с;
- скорость в км/ч.

Также сохраняется изображение с визуализацией найденного смаза.

По умолчанию результат:

```text
photo_result.jpg
```

## Выбрать область изображения

```bash
python motion_blur.py photo.jpg \
  --exposure 0.01 \
  --scale 500 \
  --roi 100 150 500 300
```

ROI — прямоугольник, начинающийся в точке `(100, 150)` с шириной 500 и высотой 300 пикселей.

## Использовать ручной порог

```bash
python motion_blur.py photo.jpg \
  --exposure 0.01 \
  --scale 500 \
  --threshold 100
```

## Для тёмного смаза на светлом фоне

```bash
python motion_blur.py photo.jpg \
  --exposure 0.01 \
  --scale 500 \
  --invert
```

## Сохранить бинарную маску

```bash
python motion_blur.py photo.jpg \
  --exposure 0.01 \
  --scale 500 \
  --mask-output mask.png
```

## Метод измерения через прямоугольник

```bash
python motion_blur.py photo.jpg \
  --exposure 0.01 \
  --scale 500 \
  --method rect
```

## Открыть изображения в окне

```bash
python motion_blur.py photo.jpg \
  --exposure 0.01 \
  --scale 500 \
  --show
```

# 15. Научная значимость

Проект демонстрирует, что фотография содержит количественную информацию о движении объекта. Смаз является не только визуальным дефектом изображения, но и физическим следствием движения во время регистрации света.

Использование компьютерного зрения позволяет автоматизировать измерение длины смаза и превратить цифровое изображение в инструмент физического эксперимента.

Таким образом, проект связывает механику, оптику, цифровую фотографию, обработку сигналов и программирование.

# 16. Ограничения метода

Метод наиболее корректен, если:

- движение приблизительно равномерное;
- камера неподвижна;
- экспозиция известна;
- объект движется в плоскости, для которой выполнена калибровка;
- смаз достаточно хорошо отделяется от фона;
- длина смаза не слишком мала относительно разрешения изображения;
- нет сильных перспективных искажений.

Если объект ускоряется, полученная скорость будет скорее средней скоростью за время экспозиции:

\[
v_{\text{ср}}=\frac{\Delta s}{T}
\]

При равномерном ускорении:

\[
\Delta s=v_0T+\frac{aT^2}{2}
\]

Тогда:

\[
\boxed{v_{\text{ср}}=v_0+\frac{aT}{2}}
\]

Это означает, что по одному смазу нельзя в общем случае определить мгновенную скорость в конкретный момент, если движение ускоренное. Для равномерного движения средняя скорость равна мгновенной.

# 17. Заключение (шаблон для итогового отчёта)

В ходе проекта был рассмотрен физический механизм формирования смаза при фотографировании движущегося объекта. Была получена зависимость длины смаза от скорости объекта и времени экспозиции.

Разработана программа на Python, использующая OpenCV для выделения смазанного объекта на изображении, определения его длины в пикселях и вычисления скорости после калибровки масштаба.

Экспериментальные результаты могут быть использованы для оценки точности метода и сравнения компьютерного зрения с традиционными способами измерения скорости.

Окончательные выводы следует сформулировать после проведения измерений и анализа погрешностей.

# 18. Краткая формула проекта

Главная формула:

\[
\boxed{v=\frac{L_{\text{px}}}{kT}}
\]

Где:

- \(v\) — скорость;
- \(L_{\text{px}}\) — длина смаза на изображении;
- \(k\) — масштаб в пикселях на метр;
- \(T\) — время экспозиции.

**Смысл проекта:** программа измеряет смаз на фотографии и, используя физические законы движения и калибровку изображения, вычисляет скорость объекта.
